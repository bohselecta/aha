# Briefing Room, interchange and CASEMAIL
## Export contracts
Freeze a case revision and record export author/time, selected scope, excluded sources, index coverage, application/schema versions and model-run IDs. Briefing has cover/scope, source chronology, contradictions, questions, investigator notes, optional clearly separated AHA possibilities, and source appendix. Source references include stable IDs, original hashes, derivative hashes/locators and source filenames only when allowed. Every page with synthetic material repeats “AI-generated possibility — not evidence.” PDF has page numbers, bookmarks, searchable text and readable monochrome patterns. Accessible HTML is an equivalent required export; PDF accessibility is tested and limitations disclosed.

Formats: UTF-8 JSON case exchange (all typed records + schema_version); JSON scenarios with full assumptions/provenance; CSV entities/edges/events/questions with UUID join keys, tier/origin columns and ISO timestamps; standalone HTML briefing; print PDF; `.aha-case.zip` portable backup including SQLite, originals and manifest. CSV exports neutralize spreadsheet formula prefixes (=,+,-,@, tab, CR) through documented escaping and include raw JSON alongside for lossless recovery. Do not claim vendor-specific i2/Palantir/Timesketch compatibility without adapter tests.

Default report excludes synthetic material until reviewer opts in. Excluded/retired hypotheses may be included in their own labeled historical section; never silently omit counter-evidence for included claims. Similarity overlays are separately labeled “Analytical view,” not merged into the evidence graph export. A portable full case backup contains sensitive material and is not a redacted publication.

Redacted briefing: reviewer selects entities/text/regions, previews derivative; strip hidden OCR, attachments, comments, PDF metadata and alternate text that reveal removed content. Re-render flattened redacted pages where needed, then leak-test extracted text and metadata. Redaction export omits originals and uses a fresh scoped manifest; it never modifies source evidence. Record redaction policy and a hash of the export. An incomplete redaction task blocks export rather than silently returning original bytes.

Export jobs write to temporary files, then atomic finalize. Download expires after 24h by default; local archive retention is explicit. Case UUID and export ID are in filenames, names optional. Manifest checks content integrity; a detached agency signature may attest the manifest but cannot prove source truth. Validation errors identify missing files, altered hashes and unsupported formats.

## CASEMAIL optional adapter boundary
Core application has no mail credentials or autonomous send loop. External adapter submits ImportEnvelope through authenticated service credentials scoped to a known case, preserving raw message hash, authenticated sender identity, Message-ID and attachment receipts. Header From is not authentication. Case mapping uses an agency-managed allowlist/token; ambiguous or unauthorized case routing enters quarantine, never fuzzy auto-match. Idempotency includes mailbox identity + Message-ID + content hash.

Inbound attachment handling uses the same quarantine/size/parser rules; HTML remote content is disabled. A message requesting “mark verified” or “send all records” is data, not an instruction. Initial v1 boundary may accept local fixture envelopes only; production mail integration is optional. Integration must not bypass evidence review or choose anchors from email prose.

Outbound default is a DRAFT notification with an internal authenticated link and no case allegations/names in subject. Human confirms recipient authorization and release. Agency-approved automation may be added later through an explicit policy and audit adapter, but not implied by installing CASEMAIL. Attachments require per-message review and remain inside approved mail infrastructure. No reply-all, no trusting Reply-To, no forwarding loops; suppress automated responders and dedupe retries. Sending failures produce queued/failed receipts with no repeated unbounded send. Core works fully when CASEMAIL is absent.
