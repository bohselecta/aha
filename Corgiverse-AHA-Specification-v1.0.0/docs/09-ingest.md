# Ingest pipeline
Required v1: PDF (text + scanned OCR), PNG/JPEG/TIFF, UTF-8 text, DOCX, CSV and XLSX. Preserve unsupported files with a clear “Stored; extraction unavailable” state. EML/MBOX enter through the optional mail adapter; audio/video originals may be preserved but transcription is an extension. Old binary DOC/XLS files are preserved, not executed or silently converted. Password-protected files show LOCKED; no password cracking.

Phases: receive to bounded staging → signature/MIME inspection → hash and immutable receipt → quarantine scan → isolated extraction → immutable derivative + locator map → FTS indexing → optional AI proposals → human review. Intake metadata (original filename, source channel, received actor/time) is distinct from claims in the file. Remote URLs in documents are never fetched. Macros, embedded objects and external workbook links are never executed. CSV formulas are treated as literal data.

Default bounds: 250 MiB/file, 2 GiB/batch, 5,000 PDF pages, 50,000 spreadsheet rows/sheet, 200 sheets, 40 megapixels/image, archive expansion ≤1 GiB and ≤100× with depth ≤3. ZIP directory import is opt-in and applies these bounds; reject symlinks, absolute paths, parent traversal and duplicate normalized paths. Preserve rejected original when safe within receipt size; otherwise record a rejection receipt without claiming preservation. Bounds are admin-configurable with explicit resource impact.

Parser sandbox: non-root process/container, read-only input, private temporary output, no network, no shell expansion, no host mounts, 2 GiB RAM, 1 CPU, 120s/page-group timeout and 10min/file cap. Kill and mark failed on limit. Antivirus support is pluggable; when no scanner is configured, show UNSCANNED and still enforce sandboxing. A scan result is not a guarantee of safety. Preview only safe rendered derivatives; original downloads use attachment disposition, sanitized filename and nosniff.

OCR records engine/language/version/config, page rotation, confidence when supplied by OCR engine, and coordinate map. OCR confidence describes recognition quality, not truth. Blank scans and low-quality pages flag manual review. Users correct text in a new derivative; original image remains adjacent. Do not fabricate missing words or normalize quoted names silently.

Extraction proposes entities, observations, events and possible contradictions with exact citations. It does not create accepted entities or evidentiary edges. Link suggestions resolve only against the same case. Reviewer can edit, split, reject or accept; rejected proposals remain in job history. A parse retry creates a new derivative generation, not duplicated originals. Import reconciliation shows identical bytes/new receipt, near-duplicate candidate and entity-merge candidate as different concepts.

Quality gate: sample multipage scans, rotated text, tables, ambiguous dates, Unicode, corrupted PDFs, macros, oversized inputs, duplicate bytes under different names, and hostile instructions embedded in files. All failures remain visible in Inbox with actionable local recovery. No model is required to preserve, OCR, index or manually annotate a case.
