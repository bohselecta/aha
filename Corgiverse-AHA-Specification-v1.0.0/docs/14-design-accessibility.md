# Visual design and usability
Tone: calm, precise, readable. Brand is Corgiverse Open Investigations; product title AHA. Avoid game-like suspicion meters, glowing “truth” signals and cinematic crime-scene styling. Light and dark themes are required; start with the host preference and remember user choice.

Desktop shell: 64px top bar with case name, search/lens field and local/offline status; 224px collapsible navigation; flexible center; 360px resizable detail drawer. At <1100px use one principal pane with drawer overlay and focus restoration. At 200% zoom reflow controls without hiding primary actions. Large evidence tables scroll within labeled regions. Base text 16px, line height 1.5, UI font system sans; monospace only for hashes/IDs. Text measure ≤80 characters for explanatory prose. 4/8/12/16/24/32 spacing scale; moderate borders, minimal shadow.

Semantic colors and patterns are in `design/tokens.json`: documented blue/solid/document icon; observed teal/solid/quote; inferred amber/dash; speculative purple/dot; contradiction red/fork; retired gray/strike/history; selected high-contrast outline. Selection never overwrites tier styling. All edges/nodes have textual accessible names and tier labels. Legend shows example strokes. Validate actual foreground/background combinations; token choice alone does not establish contrast.

Target WCAG 2.2 AA for application workflows ([W3C WCAG 2.2](https://www.w3.org/TR/WCAG22/)). Normal text contrast ≥4.5:1, large text ≥3:1, meaningful UI graphics ≥3:1. Visible focus, skip links, landmarks, logical headings, accessible error association and keyboard-complete operation. Prefer ≥44px touch targets; meet AA minimum target-size rules. Respect reduced motion and no auto-orbit; transitions ≤150ms and may be disabled. Do not announce streaming tokens continuously; announce job completion and summarized changes.

Graph table is a first-class mode with source, relationship, tier, why, date and uncertainty columns, filtering and expansion. Every insight available in 3D is available here. Timeline also has an ordered list/table. Screen reader testing uses at least NVDA/Firefox and VoiceOver/Safari; browser integration tests cover current supported Chromium and Firefox plus Safari/WebKit flows. Canvas screenshot tests do not demonstrate accessibility.

Required microcopy: “Recorded in a source; not independently established”; “Reported observation”; “AI-generated possibility — not evidence”; “Shared similarity; no evidenced relationship”; “No matches in indexed material”; “This result uses an older case revision”; “Retired explanation: new evidence and review required.” Buttons: “Review source,” “Why shown?”, “Generate possibilities,” “Questions worth checking,” “Clear lens,” “Export briefing.” Avoid “Solve,” “Detect suspect,” “Truth score,” or “Most likely.”

First-run tour uses the synthetic case and ≤5 steps. Standard workflow needs no prompt syntax. Persist local view preferences, not case contents in browser localStorage; clear cached content on logout/case switch. No service worker caches sensitive responses by default. Support printable help, plain-language errors and a diagnostics export with content redacted.
