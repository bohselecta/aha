# Case Atlas, timeline and optional Scene View
## Atlas
Use Three.js behind a renderer interface, with 2D SVG/canvas and a fully operable semantic table. WebGL failure, reduced-motion preference or low-performance mode selects 2D/table automatically with a visible explanation. Core actions cannot require dragging or precise orbit control.

Meaningful 3D mapping: x is occurrence time for event instances; y is a stable, labeled entity/event grouping lane; z is the basis layer DOCUMENTED / OBSERVED / INFERRED / SPECULATIVE. Depth is categorical, not a continuous confidence axis. People and source documents occupy non-temporal side lanes and connect to event instances; do not invent a timestamp for an entity. Unknown dates live in an “Undated” region. Layout coordinates never stand for real geography. Toggle to a topology-only 2D view when time/layer encodings do not aid the task.

Use stable, seeded ordering by group and ID; preserve pins per view. No continuously moving force simulation. Expand neighborhoods on request; initial overview clusters large groups and states counts. Cluster links carry aggregate counts and mixed-tier markings, never imply an evidenced connection between every member. Selecting expands underlying records. Recompute layout in a worker. Instanced geometry, batched edges and label culling preserve frame budgets. Dispose GPU resources when switching cases.

Single click selects; Enter opens detail; Esc backs out; F focuses; Home resets; plus/minus zoom; arrow keys move within table/list; search always accessible. Visible buttons duplicate shortcuts. Keep keyboard focus in DOM, not trapped in canvas. Provide breadcrumb “Case → Lens → Entity → Edge,” edge/source deep links and accessible selection announcements. A pinned legend remains visible; colors, patterns, icons and words jointly communicate status. Screenshots include legend, case revision and synthetic labels.

## Timeline
Store raw source time, occurrence bounds, precision, timezone, source clock and discovered/recorded times independently. UTC normalized bounds only when enough timezone/offset information is known. Unknown timezone keeps raw local time and appears in a separate unresolved lane; no silent system-timezone assumption. Ambiguous daylight-saving times require explicit fold choice or both possible intervals. Invalid local times require review. Date-only means the whole local day, including DST-length days. Approximate times require explicit tolerance; no hidden default ±5 minutes.

Intervals use explicit start_inclusive/end_inclusive flags; occurrence uncertainty defaults to closed bounds, but “before 22:10” has an open upper bound. Null RANGE endpoints are unbounded, not zero; at least one bound must exist. Exact has equal inclusive bounds. Filtering honors boundary flags. Before/after strictness is explicit. Disputed time stores competing event versions/claims, not an average. Clock correction is a separate sourced interpretation with offset bounds and version, applied as a derived view; raw timestamp never changes. Spatial/time plausibility cannot outrank an accepted source automatically.

Timeline shows uncertainty bands, labels, locked-anchor pins and disputed forks. Dragging proposes a new interpretation, never edits source time directly; locking requires review reason. Occurrence/discovery/recorded selector is prominent. Zoom from years to seconds; dense ranges aggregate with counts. Undated and excluded material remains reachable. Align AHA paths below the source chronology with synthetic step bands and clear separator.

## Optional Scene View extension
Separate physical coordinate system from Atlas. Metric units, coordinate reference/frame, scale origin, alignment method and source are mandatory. SceneObject schema includes evidence tier, source references, geometry asset hash, transform and uncertainty radius. No measured dimensions → visibly schematic, with measurement/visibility conclusions disabled. Every object is independently inspectable; estimated positions show uncertainty volumes. A source photograph is not automatically a calibrated reconstruction.

Ray/occlusion queries are geometric calculations over modeled surfaces and uncertainty samples. Outputs say “line of sight under this geometry,” never “witness could identify the person.” Lighting, lens, weather, obstruction and human perception are unmodeled unless supplied. Proposed routes are synthetic paths, not reenactments. AI-produced geometry starts SPECULATIVE and requires measurement review to create a new supported version. No automatic photorealistic reconstruction presented as evidence. Extension acceptance requires uncertainty sweeps, measurement calibration tests, schematic watermark and equivalent numeric/table output. Hide the feature in v1 unless these gates pass.
