# Contracts
Validate the root as CaseExchange or select `#/$defs/<Name>` for a payload. The example.org-style schema host `corgiverse.example` is an identifier, not a runtime network dependency; bundle resolution locally. All object definitions are closed. ISO timestamps, UUIDs and SHA-256 strings require format/pattern checking. Lists are bounded. Domain enums are not free-form user labels.

Server must additionally enforce semantic requirements in docs/03-domain.md–docs/07-query-search.md: reference existence/type/case/version, source hash and locator validity, authority, lifecycle, constraints, source independence and synthetic non-promotion. Schema-valid does not mean evidence-valid. Generate Pydantic/TypeScript types; do not hand-maintain divergent models.

CaseExchange is a full versioned interchange; multiple revisions of one UUID are allowed, duplicate (id, revision) pairs are not. Incremental imports require a separate future merge protocol. The seed is not a ready-to-open SQLite case until the app importer constructs storage and audit receipts.
