# Start the implementation
Build Corgiverse Open Investigations / AHA end to end from this package. Treat README, AGENTS, invariant register, schemas, API and acceptance checklist as the build contract. This package is a specification; application source and images still need to be created.

First validate the bundled contracts and fixtures. Initialize the target monorepo from docs/18-delivery.md without discarding this spec. Pin compatible dependencies and create IMPLEMENTATION_STATUS.md mapping each acceptance ID to code/tests/evidence. Implement M0 through M7, delivering usable vertical slices. Prioritize evidence integrity, source review and deterministic rules before generative features. Continue through the full required scope; do not stop after scaffolding or a synthetic UI demo.

Use a real local model adapter plus an explicitly labeled replay provider. Validate every output at schema, reference and semantic layers. Keep UI clear for nontechnical investigators, and supply table/keyboard equivalents for all graph work. Verify supported formats, offline operation, backup/restore, redaction and adversarial inputs. CASEMAIL and calibrated Scene View are optional extensions, not substitutes for required functionality.

At each milestone report completed requirements, tests actually run, failing/unverified gates and next milestone. Final handoff includes runnable local release, setup/operator/user docs, schemas/migrations, synthetic demo, SBOM/licenses, test evidence and every acceptance outcome. Never label untested or partial work production-ready.
