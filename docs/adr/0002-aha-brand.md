# ADR 0002 — Aha! product name and supplied logo

Status: accepted, 2026-09-16. Authority: the user's explicit request to use the supplied corgi logo and call the product “Aha!”.

Use **Aha!** as the visible product name, with **Open Investigations** as the descriptor. Preserve the supplied PNG unchanged in `apps/web/public/brand/aha-logo.png`; render it on a white plate so its dark lettering remains legible in both themes. Use it in the application header, first-run screen and browser icon. No generated substitute or image alteration is needed.

Keep the original specification, technical schema names, API routes, case format and historical package filenames unchanged. The naming preference does not weaken any evidence-integrity or human-review requirements.
