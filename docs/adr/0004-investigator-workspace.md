# Investigator-facing workspace

The user requested a professional, approachable tool and removal of builder-facing product copy. The original “AI cold case assistant” conversation reinforces source tracing, visual exploration, separate evidence and interpretation, preserved contradictions and retired ideas, and questions that distinguish possibilities. No transcript or private research content is included in the product.

`packages/workbench` now supplies the same read-only case explorer to the local application and the public fictional case. It includes a stable two-dimensional map, record table, source chronology, conflict/question/hypothesis inspection, saved scenarios and source passages. The local application's inspector opens the actual preserved source through its existing integrity-checked endpoint. The public site contains only the supplied fictional fixture.

Keyword search is deterministic and labeled. It matches all search words in labels, statements and cited passages; it is not a natural-language compiler, FTS, embeddings or AI generation. Connections come only from version-resolved citations, named-subject references, event references and accepted relationship records. Relationship basis is independent of endpoint basis. Shared words create no edges. Position and selection survive filtering; search is a view only.

The map is capped at 80 records; tables/cards at 500 matches and links at 1,500, with visible truncation notices. This is not completion of the full large-case or 3D specification. Source and case records are never saved in browser storage. Existing M0–M7 acceptance work remains in the developer documentation. The UI retains useful source uncertainty and a brief evaluation/sample label instead of development commentary.
